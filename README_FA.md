# مدرسه‌یار — اپلیکیشن اولیا | طرح B رسمی سازمانی

**نسخه سورس: 1.2.0** · Android / React Native / Expo SDK 58 · RTL · تم سرمه‌ای، سفید و طلایی

این بسته سورس کامل پروژه است؛ **APK آماده نصب نیست**. طراحی مرجع `design/approved-B-reference.png` است و تغییر تم یا چیدمان از طرح B انجام نشده است.

## ارتقاهای نسخه ۱.۲.۰

### صفحات بومی اضافه‌شده
- **تحلیل پیشرفت تحصیلی:** انتخاب بازه هفتگی، ماهانه، سه‌ماهه، نیم‌سال و سالانه؛ فیلتر درس؛ نمایش میانگین، روند، نتایج نهایی آزمون، نقاط نیازمند تمرین و نظرهای منتشرشده معلم.
- **حضور و غیاب روزانه:** دریافت وضعیت رسمی زنگ‌به‌زنگ، انتخاب تاریخ میلادی، حاضر/غایب/موجه/غیرموجه/تأخیر، زمان ثبت معلم و ورود آنلاین. «ثبت نشده» هرگز به‌عنوان غیبت نمایش داده نمی‌شود.
- **دعوت ملاقات مدرسه:** مشاهده دعوت‌های معلم، پذیرش، اعلام عدم امکان حضور یا درخواست زمان دیگر؛ پاسخ به سرور و قابل مشاهده در پنل مدرسه.
- **درخواست غیرحضوری:** ارسال درخواست دسته‌بندی‌شده عمومی، آموزشی، اداری یا رفاهی به کارتابل مدرسه.
- **مدیریت نشست‌ها:** مشاهده دستگاه‌های متصل، تشخیص نشست جاری، لغو یک دستگاه، خروج از سایر دستگاه‌ها و لغو همه نشست‌ها.
- **ثبت مشخصات دستگاه:** ثبت پلتفرم و برچسب اپ روی نشست جاری، در صورت پشتیبانی API.

### امکانات قبلی حفظ‌شده
- داشبورد طرح B، انتخاب بین فرزندان متصل، اطلاعات فرزند و تصویر پروفایل.
- کارنامه رسمی منتشرشده و چاپ، تکالیف، برنامه هفتگی، تقویم و رویدادها.
- اطلاعیه‌ها، رضایت‌نامه‌ها و پاسخ تأیید/عدم موافقت.
- فهرست کلاس‌های آنلاین و باز کردن لینک HTTPS پس از تأیید مقصد.
- درخواست ملاقات والد و پیگیری درخواست‌های قبلی.
- ورود با کد ملی ولی و رمز، تغییر اجباری رمز اولیه، خروج امن و مدیریت نشست.
- **تمام ۹ نمای وب اولیا** همچنان از داخل اپ در دسترس‌اند: خانه، مشخصات، کارنامه، گزارش آزمون، حضور و غیاب، تکالیف، برنامه، ارتباط با مدرسه و تنظیمات. بخش‌هایی که هنوز صفحه بومی مستقل ندارند از پنل اصلی در WebView امن باز می‌شوند؛ هیچ بخش وب حذف نشده است.

## اثر انگشت و امنیت
- فعال‌سازی فقط زمانی پیشنهاد می‌شود که سیستم‌عامل وجود حسگر اثر انگشت و اثر انگشت ثبت‌شده را گزارش کند.
- هنگام بازگشت اپ از پس‌زمینه، صفحه قفل می‌شود و احراز هویت با غیرفعال‌کردن fallback رمز دستگاه درخواست می‌شود.
- توکن در `expo-secure-store` نگهداری می‌شود و داده خام اثر انگشت در اپ ذخیره نمی‌شود؛ بررسی بیومتریک توسط سیستم‌عامل انجام می‌شود.
- اگر گوشی علاوه بر اثر انگشت، تشخیص چهره هم داشته باشد، انتخاب نوع بیومتریک نهایی در اختیار Android است؛ Expo امکان اجبار سخت‌افزاری به «فقط اثر انگشت» را در همه مدل‌ها نمی‌دهد. در گوشی‌ای که تنها اثر انگشت دارد، همان اثر انگشت برای ورود استفاده می‌شود.
- اگر اثر انگشت حذف شود یا دسترسی بیومتریک از دست برود، ورود با رمز عبور در دسترس می‌ماند.
- مسیرهای API محدود به `/api/guardian/*` هستند؛ توکن در هدر Bearer ارسال می‌شود؛ لینک‌های خارجی فقط با HTTPS و تأیید کاربر باز می‌شوند.

> نکته: نمایش نهایی پنجره احراز هویت و سیاست‌های بیومتریک تابع نسخه اندروید و سازنده گوشی است. قبل از انتشار عمومی، اثر انگشت باید روی گوشی واقعی و با APK نهایی آزمایش شود.

## قراردادهای API مورد استفاده

- `POST /api/guardian/login`, `POST /api/guardian/logout`, `POST /api/guardian/change-password`
- `GET /api/guardian/dashboard`, `GET /api/guardian/student-analysis`, `GET /api/guardian/student-dossier`, `GET /api/guardian/attendance-day`, `GET /api/guardian/exam-report/t06`
- `POST /api/guardian/meeting-request`, `POST /api/guardian/meeting-invitations/respond`, `POST /api/guardian/contact-request`, `POST /api/guardian/consents/respond`
- `GET /api/guardian/sessions`, `POST /api/guardian/sessions/client-info`, `POST /api/guardian/sessions/revoke`, `POST /api/guardian/sessions/revoke-others`, `POST /api/guardian/sessions/revoke-all`

درخواست‌ها به حساب ولی احراز هویت‌شده متصل‌اند و شناسه فرزند انتخاب‌شده در درخواست‌های وابسته به دانش‌آموز ارسال می‌شود. سرور مرجع دسترسی نهایی را کنترل می‌کند.

## مرجع و تطبیق نسخه وب

- ساختار رابط وب اولیا و ۹ نمای آن با `STAGE48_SOURCE_72_82_0.zip` (شامل `guardian/app.js`, `guardian/index.html`) تطبیق داده شده است.
- مسیرهای API جدیدتر از سورس سرور موجود در پروژه بررسی شده‌اند؛ پیش از انتشار عملیاتی باید نسخه واقعی هاست مدرسه نیز با همین قراردادها تطبیق داده شود.
- برنامه به دیتابیس یا فایل‌های هاست دسترسی مستقیم ندارد و فقط از API استفاده می‌کند.

## ساخت APK آزمایشی

پیش‌نیاز: Node.js 22، npm، اینترنت برای دریافت پکیج‌ها و حساب Expo/EAS. در PowerShell ویندوز:

```powershell
cd "C:\path\to\madreseyar-parent-mobile-B-v1.2.0"
npm install
npm run verify
npx eas-cli@latest login
npx eas-cli@latest build --platform android --profile preview
```

پروفایل `preview` در `eas.json` خروجی APK می‌سازد. نسخه `versionCode` اندروید به ۳ افزایش یافته است.

### اتصال به سرور

در اولین اجرا، نشانی HTTPS سرور پنل اولیا را وارد کنید؛ مسیر `/guardian/` نیز پذیرفته می‌شود. یا فایل `.env` بسازید:

```env
EXPO_PUBLIC_PARENT_PORTAL_URL=https://YOUR-SCHOOL-DOMAIN.example
```

SSL معتبر و دسترسی موبایل به API الزامی است. از اطلاعات واقعی دانش‌آموز در گزارش خطا یا مخزن عمومی استفاده نکنید.

## نتیجه آزمون این نسخه

- **۲۴ آزمون خودکار Node.js موفق**: دسترسی دانش‌آموز، قرارداد API، درخواست ملاقات، پاسخ دعوت ملاقات، درخواست غیرحضوری، رضایت‌نامه، نشست‌ها، وضعیت حضور، چاپ و لینک‌های خارجی.
- **تجزیه JSX با TypeScript موفق**.
- نصب وابستگی‌های Expo در این محیط به پایان نرسید (فرآیند `npm install` به مهلت اجرا رسید)؛ بنابراین APK ساخته نشده است.
- اجرای اپ روی گوشی واقعی، اثر انگشت واقعی و اتصال به هاست عملیاتی هنوز نیازمند آزمایش است.
