# مدرسه‌یار | اپلیکیشن اولیا — طرح B

سورس نسخه 1.2.2 برای Android / React Native / Expo.

## ساخت APK مستقیماً در GitHub

این مخزن دارای GitHub Actions است. با هر Push به شاخه `main`، یا با اجرای دستی Workflow، گیت‌هاب پروژه را بررسی و APK آزمایشی قابل نصب می‌سازد.

### مراحل
1. در GitHub یک مخزن جدید بسازید. پیشنهاد: `madreseyar-parent-app`. اگر سورس را عمومی نمی‌خواهید، مخزن را **Private** بسازید.
2. تمام محتویات این پوشه را در ریشه مخزن بارگذاری کنید. پوشه مخفی `.github` و فایل `.github/workflows/build-android-apk.yml` حتماً باید بارگذاری شود.
3. به زبانه **Actions** بروید.
4. Workflow با نام **Build Android APK** را انتخاب کنید.
5. روی **Run workflow** بزنید و شاخه `main` را انتخاب کنید.
6. پس از پایان موفق، وارد اجرای همان Workflow شوید و در بخش **Artifacts** فایل `madreseyar-parent-v1.2.2-standalone-debug-apk` را دانلود کنید.
7. ZIP دانلودشده از Artifacts را باز کنید؛ فایل `app-debug.apk` داخل آن است.

### نوع خروجی
این Workflow یک **Debug APK مستقل و امضاشده با کلید debug** تولید می‌کند. فایل JavaScript داخل APK قرار می‌گیرد و برای اجرای برنامه به Metro یا اتصال به رایانه نیاز نیست. پیش از انتشار Artifact، وجود فایل bundle در APK بررسی می‌شود. این خروجی نسخه انتشار عمومی فروشگاه نیست. برای انتشار نهایی باید کلید امضای اختصاصی Release تنظیم شود.

### پیش‌نیازهای پروژه
- Node.js 22
- Java 17
- Expo SDK 58
- Android package: `ir.madreseyar.parent`

### تنظیم اتصال به سامانه
در اولین اجرای برنامه، آدرس HTTPS پنل اولیا/سرور مدرسه را وارد کنید. همچنین می‌توانید مقدار `EXPO_PUBLIC_PARENT_PORTAL_URL` را طبق فایل `.env.example` تنظیم کنید؛ اگر این مقدار در مخزن عمومی قرار می‌گیرد، فقط آدرس عمومی سامانه را بنویسید و هیچ رمز یا توکن محرمانه‌ای را وارد نکنید.

راهنمای کامل فارسی در `README_FA.md` قرار دارد.
